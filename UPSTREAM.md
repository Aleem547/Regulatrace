# Upstream source and contribution record

Regulatrace adapts original regulatory-research code by
[Faizan0602](https://github.com/Faizan0602) and upstream contributors.
The original repository is identified by its stable
[GitHub repository record](https://api.github.com/repositories/1403548102).
The supplied source archive contained 124 files. Existing implementation,
authorship references, evaluation artifacts and historical findings are retained.

This distribution adds deployment configuration checks,
combined frontend/API container packaging, explicit PostgreSQL driver compatibility,
an index preparation command and deployment documentation. These additions do not
establish authorship of the original application or its benchmark experiments.

The supplied package metadata declares MIT, but the supplied archive contains no
standalone license text or copyright notice. No new license grant or transfer of
the original authorship is asserted by this adaptation.
